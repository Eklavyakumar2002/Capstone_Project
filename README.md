# Capstone_Project
This project is a capstone automation testing framework developed using Java, Selenium WebDriver, Maven, and TestNG. The framework automates end-to-end testing  and follows industry best practices.
#**Selenium Automation Framework**
A robust and scalable Selenium Automation Framework built using Java, Selenium, TestNG, Maven, and Jenkins following the Page Object Model (POM) design pattern.

Features
Parallel Execution
Headless Browser Execution
Jenkins CI/CD Integration
Extent Reports
Data-Driven Testing
Shadow DOM Handling
Drag & Drop Automation
Dynamic Web Tables
File Upload & Download
Utility-Based Reusable Framework
